# Midas Word List

Words to keep out of public copy about Midas: pitches, bios, the essay, landing pages,
App Store text. Internal docs and code can use them freely.

Source column: **founder** = named by the founder (2026-10-06); **agent** = added by an agent
from the same rule ("keep it vague, no technical details"). The founder can strike any agent row.

## Do not use

| Word or phrase | Source | Say instead |
|---|---|---|
| container | founder | home, place |
| shell | founder | (describe what it does: "lives on your phone") |
| app builder | founder | "makes it for you" |
| builder, no-code, low-code | agent | "you describe it, Midas makes it" |
| generate, generator, generated | agent | make, made for you |
| deploy, deployment, hosting, host | agent | "shows up on your phone" |
| platform, infrastructure, backend | agent | Midas |
| mini app, mini-app | agent | personal software, Sidekick |
| WebView, WKWebView, SwiftUI | agent | (leave out) |
| Cloudflare, Workers, D1, R2, Hono | agent | (leave out) |
| LLM, model, prompt, agent | agent | (leave out, or "in your own words") |
| SDK, API, runtime, sandbox | agent | (leave out) |
| jess | agent | (leave out; the assistant is not public yet) |

## Use

- personal software
- Sidekick, Sidekicks
- in your own words
- private, yours, made for you
- keeps it working, grows with you
