## ⚠ Plan-relevant
- Wabi — Wabi 2.0 (announced Sep 28–29): pivot from app-builder to an invite-only "agentic messenger" that builds apps and UIs on demand inside group chats with friends/family; Kuyda says invites keep going out (Oct 1) and the iPhone app remains the product. This is the closest competitor converging on personal software + apps + people in one place, but it stays chat-first — no home-screen presence, private named-people deploy, or per-person data store surfaced so far. Midas's phone-shell differentiators still hold; the social/group angle (trip planning, family calendars) is where Wabi is pulling ahead conceptually. — [TechCrunch](https://techcrunch.com/2026/09/29/ai-powered-app-maker-wabi-pivots-to-a-messaging-experience/), [runtimewire](https://runtimewire.com/article/wabi-2-agentic-messenger), [Kuyda on X](https://x.com/ekuyda/status/2105458877777273289) — confirmed.
- OpenAI — DevDay (Sep 29): Dots, always-on agents (GPT-6 Astra, own cloud computer, 4,000+ apps), plus plugin extensions — "essentially entire applications that feel native to ChatGPT," distributed through OpenAI — and texting "coming soon." Watch item: if ChatGPT/Dots gain texting or user-built apps on mobile, they become the ambient-agent endgame that leaves Midas only the native shell. For now dots are Pro/Business Premium, desktop/web-first (mobile messaging only), EEA/UK excluded at launch. — [OpenAI: Introducing dots](https://openai.com/index/introducing-dots/), [CNBC DevDay recap](https://www.cnbc.com/2026/09/29/openai-devday-2026-live-updates.html) — confirmed.

## Competitors
- Google — Opal (mini-app builder) and "Gems made by Labs" shut down Nov 17, 2026; the ideas fold into Gemini Skills (slash-command prompts, free, rolling out globally). Opal workflows get no automatic migration. A direct-ish competitor exits the mini-app space; "skills" are just reusable prompts, not apps with UI — signals Google sees no standalone consumer mini-app product worth shipping. — [Opal FAQ](https://developers.google.com/opal/faq), [Google blog](https://blog.google/products-and-platforms/products/gemini/automate-tasks-with-skills/) — confirmed.
- Anthropic — Claude Code "mods" (Oct 1): TypeScript functions that rewrite prompts, add UI, or replace built-in features; plugins are now the main third-party extension path with a directory, MCP 2.0 and MCP Apps support (Sep 25). MCP Apps = interactive UI in chat, still chat-hosted, not phone-local — no change to the local-notification/offline gap. — [claude.com blog via Releasebot](https://releasebot.io/updates/anthropic/claude) — confirmed (via aggregator quoting official blog).
- Replit — ongoing cadence: Oct 2 release notes add GPT-6.1 Sol / Sonnet 5.5 to Agent, redesigned Settings; desktop MCP client so other AI tools can create/publish Replit apps; Meta device support incl. Muse app creation (Sep 25); Atta acquisition for in-chat charts (Sep 25). Nothing new on private/personal publishing or phone surfaces. — [Replit blog](https://replit.com/blog), [Releasebot](https://releasebot.io/updates/replit) — confirmed.
- Lovable — annualized revenue crossed $600M (Sep 24, HumanX; up from $500M in June; apps built on it get ~1B visits/mo); free "Chats" mode (Sep 24); disclosed a TanStack Start vulnerability (CVE-2026-102989) found by its own security team and firewall-protected hosted apps (Sep 30). Mobile app (iOS/Android) is a builder companion, not a private-app shell. — [lovable.dev/blog](https://lovable.dev/blog), [TechCrunch tag](https://techcrunch.com/tag/lovable/) — confirmed.
- Base44 / Wix — Superagents can now manage Base44 apps directly (list, edit, build, call backend functions) and the Superagents tab in the Base44 mobile app went fully native; connector/skills ecosystem growing. An agentic app-builder with a real native mobile app, but no personal mini-app shell or private deploy story. — [Base44 product changelog](https://docs.base44.com/changelog/product) — confirmed (changelog undated; items recent).
