## Personal software / the phenomenon
- Daniel Corin, "Personal Software" — new find: he built "frame", a single Swift shell app on iPhone listing agent-built webapps from a JSON manifest, with a WKWebView JavaScript bridge (`window.Frame`) routing storage through CloudKit for private, cross-device data, and webapps falling back to `localStorage` in a plain browser. He builds and manages the apps entirely from his phone via a stateful Slack agent (describe → agent scaffolds → GitHub Actions deploys to Cloudflare Workers → manifest update → app appears in frame). This is the Midas pattern (phone shell + web sidekicks + one private per-person data store) hand-rolled by one person — strong validation of the design, and prior art worth citing before the Nov 2 application. — [Post](https://www.danielcorin.com/posts/2026/personal-software/) — reported (page shows no date; surfaced in this run's searches).
- YC Fall 2026 RFS "A Cloud for Small Software" (Pete Koomen) — standing thesis, background only: small software is easy to build, hard to deploy and share; investor attention sits exactly on Midas's deploy/share/upkeep differentiators. — [ycombinator.com/rfs](https://www.ycombinator.com/rfs)
