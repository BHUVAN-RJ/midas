Add to Home Screen: four sheets (iOS 26/27 look)

One sheet for every Sidekick with a widget, drawn by the app in Midas ink on paper, in the current system look: a Liquid Glass sheet inset from the screen edges, round glass close button top-left, capsule buttons. The preview is the Sidekick's own widget (here Water). Steps follow iOS 26/27: touch and hold the Home Screen, Edit (top-left), Add Widget, the app, Add Widget. A new "Sidekick" widget shows the last Sidekick opened, so nothing to edit after.

B and C draw the real iOS screens: glass app icons, floating dock, the Edit menu (Add Widget, Customize, Edit Pages), the widget gallery with its capsule search field, the app's size pages.

How it is reached

PieceWhat
In a SidekickAn "Add to Home Screen" button (Water: in Settings, and once after first open). The page asks the app; the app opens this sheet. Same for any Sidekick with a widget.
The sheetNative SwiftUI sheet (medium detent), so Liquid Glass comes from the system. One for all Sidekicks; the preview is the Sidekick's own filled widget.
After "Add Widget"The new widget shows the last Sidekick opened, so it is Water at once.
Not possiblePlacing the widget for the person: iOS has no call for it (iOS 27 SDK, WidgetKit).
