  • No app build per sound. Each reminder can have its own sound.
  • Repair can add it later: an optional sound field, no breaking change.
  • Library/Sounds is a folder Apple lists for sounds. Copying files there while the app runs: not tested by us yet. Needs one try on an iPhone.
  • Only aiff, wav or caf, under 30 s. Longer → default sound plays.
  • mp3 / m4a from Files would need converting by the shell first (not checked).
  • Recording in the Sidekick: no (no microphone in Sidekicks). Picking a file: yes.
  • No custom vibration, either way (Apple).

  • Home Screen on iPhone has 3 sizes. All 3 work in the shell now.
  • Repair changes the widget: layout, words, colours, which size shows what.
  • Repair adds a missing size (e.g. Reminders gets a large).
  • Repair adds a second widget (widget:week next to widget:today): the widget doc allows it, but the Reminders repair rules only mention widget:today. Not tried.
  • Any repair that changes the page also updates the widget, so it never breaks.
  • A new piece or a new tap type → app build, not repair.
  • Lock Screen sizes → not built yet.
