Money icon

Six drawn options for Money's tile, in the same craft as Water's Glass: one ink outline, flat fills, a 100-unit canvas. Each is shown at 120, 60 and 29 pt, then on a Home Screen row next to Water, Reminders and Care, in light and dark. Option 0 is today's SF Symbol tile, which has to go.

Notes

Recommendation: D · The bar

It is Money's own picture. Option B's page is a big month total over one bar split into the category colours, and the icon is exactly that, in miniature: an ink stroke for the total and the split bar under it. It is the only option that cannot be any other money app's icon, the colours come from Money's categories (nothing invented), and it still reads as "a bar of colours" at 29 pt, where the wallet and folded bill turn into blobs. On the home row it sits well beside the Glass and Reminders: white tile, ink, one band of colour.

Runner-up: F · Jar. It is the Glass's sibling (an ink vessel filling up), so Water and Money look like a set. Against it: a jar reads as saving, and Money tracks spending. A · Receipt is the other good pick: it says "photo of a receipt", Money's headline input.

Avoid B · Stack: coins are on DESIGN.md's "never" list for the Midas mark (a crown, a coin, gold imagery). That rule is about the mark, but a coin tile next to the name "Midas" pulls the same way, so it is drawn here in green and paper, never gold, and still not recommended.

What production needs once one is chosen (the Water precedent, commit f9efc77)

  1. Drawn by the shell, not a PNG. Like the Glass: a new SidekickArtwork case (for example .moneyBar) mapped from the id "money" in shell/Shared/SidekickIcon.swift; a MoneyBarArtwork enum with the light and dark hex values, colors(isDark:) and the paths on the 100-unit canvas copied from this page; a MoneyBarIcon view drawing them in a Canvas scaled to the tile. Vector, so one drawing serves every size: 60 pt home grid, widget folders, Make, sheets, 29 pt lists. The file is compiled into the app and the widget extension, so widgets get it too.
  2. Both palettes in the same change (docs/ICONS.md): light and dark hex values as shown on this page, plus a row in the ICONS.md table.
  3. Manifest fallback kept in step: sidekicks/money/manifest.json's icon.background / backgroundDark changed to the artwork's tile colours (for builds without the artwork). The symbol stays only as that fallback.
  4. Tests, as WaterIconTests.swift: Money maps to the artwork, not its symbol; every colour parses as hex in both palettes; the outline's bounding box matches this mockup; one geometry check that can fail (D: the segment widths add to the bar's width and are in the category order; F: the jar clips its bands).
  5. It is a shell change, so a new app build: bump the build, update docs, founder archives. A repair agent cannot change it (it only edits manifest colours).
  6. Only if a raster is ever wanted (the jess and Make route): 1024 x 1024 light and dark PNGs in Shared.xcassets, rendered headless from an SVG as in shell/icon-source/README.md. Not needed for any option here.

Aside, outside this brief: Care's shipped icon has one lavender tile (#C9B3FF) in CareUrgencyArtwork; it is shown here as it ships.
