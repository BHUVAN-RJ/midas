App Review · 2.5.2

Bans downloaded code that adds features.

1 · TemplatesData only. Rule doesn't apply. Same as Reminders widget today.
2 · DescribedData drawn by shell code. Apps already live doing more:
{ }Scriptable · JS widgets WWidgy · shared JSON designs
Apple's wording

2.5.2: apps may not "download, install, or execute code which introduces or changes features or functionality of the app."

DPLA 3.3.1(B): interpreted code may be downloaded if it keeps the app's advertised purpose, doesn't bypass signing or sandbox, and creates no app store.

Also met: 2.5.16 (widgets match app content). 4.7.2: Sidekick only writes data; shell draws.
