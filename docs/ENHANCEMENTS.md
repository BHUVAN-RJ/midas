## 1. Match spoken words to the drawing (raised 2026-10-13)

Feature: repair (gesture, draw on the screen, speak; `docs/PRODUCT.md` section 2, "Plan
additions, 2026-10-13: repair").
When a user says "I need it here" while drawing, the repair agent should know which stroke "here"
means: line up the transcript's word timings with the drawing's stroke timings, so each "here",
"this" and "that" points at a place on the screen. Not built with the first version (founder,
2026-10-13: "an enhancement, not the core of the feature").
